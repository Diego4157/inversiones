# JD Inversiones & Asset Management

Sistema integral para la gestión de créditos, inversiones y activos propios.

## Características
- **Módulo de Créditos**: Gestión de cartera, refinanciación e historial.
- **Módulo de Activos**: Lógica de "Cajones de Ahorro" para motos (Boxer CT 100).
- **Inversionistas**: Liquidación de ganancias mensuales.
- **Recibos**: Generación de PDF (8 recibos por hoja carta).
- **PWA**: Instalable en móvil y escritorio.

## Tecnologías
- **Frontend**: React, Tailwind CSS, Lucide Icons, Framer Motion.
- **Backend**: Node.js, Express, PostgreSQL, Prisma.
- **PWA**: Vite PWA Plugin.

## Instalación
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`.
3. Configurar base de datos en `server/.env`.
4. Correr frontend: `npm run dev`.
5. Correr backend: `cd server && node index.js`.
